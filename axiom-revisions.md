# Axiom revisions

The axioms changed as the framework grew, each revised to stay consistent with the others. This page keeps the record of what changed and why; the current wording is on [Axioms](axioms.md).

| Axiom | What changed | Why |
| --- | --- | --- |
| Causation | "All things have an origin" became "every event has prior conditions." | A random event starts a new branch mid-chain, so chains don't always trace back to one origin. |
| Interaction | One-way contact was explained by time: causes run only forward. Now it is explained by channels: contact runs one way only where there is no channel back to the source. Later: channels have widths, so two-way contact can still be lopsided, and power tends to widen the channel out and narrow the channel back. | Time was only one way of being out of reach. The past and a dead star's light are one-way for the same reason, while a living star's light still makes a relation possible. Broadcast had been listed as one-way, which contradicted the broadcast paragraph; it is two-way but lopsided, and it moved into Interaction. |
| Constraint | Freedom as "free from all constraint" was dropped; freedom from interference by other people stays. The line between precarity and impermanence was redrawn. | Everything that exists is constrained, so total freedom from constraint is incoherent. Precarity comes from natural and social sources alike; what sets it apart from impermanence is that it can be reduced. |
| Emergence | Specified as weak emergence. Quark flavors corrected from three to six. | Strong emergence would give higher levels new causal powers, sneaking agent causation back in against Causation. |
| Unbidden Thoughts and Desires | Clarified: the axiom defeats ultimate responsibility, not Frankfurt's structural account. | Frankfurt already allows that we don't author our desires. Reflection still shapes later desires indirectly, since thoughts beget thoughts. |
| Compression | Time settled as a compression of change and finitude. | Change and finitude are the real constraints (see Constraint); "time" is the concept minds build from them. |
| Hypothetical Imperative | Suffering went from "avoided at any cost" to "aversive by definition," and was separated from failure to flourish. | People rightly accept suffering for meaning. They can also flourish while suffering, and fail to flourish without suffering. |

New changes get logged here, so the Axioms page can read as the current version.
